PRIMARY GOAL:
Modify ONLY the mouth of the original character to a clear L/E-style speech shape while keeping the character perfectly identical in every other aspect.

This must remain the EXACT SAME character from the base image (Rick Sanchez from Rick and Morty).
Preserve face structure, jawline, chin shape, lip style, hair, eyes, clothing, pose, arms, and lighting exactly.
Do NOT redesign or restyle anything.
The reference image "L" is ONLY for mouth geometry guidance.

STRICT FORMAT LOCK:
Maintain exact 1:1 square aspect ratio, identical framing, zoom, center position, head placement, and body alignment.
No camera movement, no crop changes. Output must align perfectly over the original.

MOUTH TRANSFORMATION (L/E):
Create a moderately spread, speech-ready L/E mouth shape.
Keep vertical opening small to medium (not wide open).
Corners may be slightly widened but not smiling.
No exaggerated teeth display.
Maintain Rick's original line treatment, lip thickness, and mouth width proportion.
Expression remains neutral, slightly bored and analytical.

STYLE + BACKGROUND LOCK:
Keep Rick and Morty style, line thickness, cel shading, and face-light match unchanged.
Use solid pure green background #00FF00 (flat, no gradient, no texture, no shadows).

TECHNICAL REQUIREMENTS:
Square format (1:1), same resolution as input, clean stable line art, no motion blur, no face distortion, no geometry shift, no flicker.
